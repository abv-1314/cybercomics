# Паспорт выпуска (для выпусков 10–22)

Рядом с фрагментом `<slug>.html` положи `<slug>.meta.json` — по нему сайт рисует шапку выпуска, карточку на главной и вопросы в «Повторении».
Формат (как в const ISSUES в src/pages/IssueReader.dc.html; русский текст):

```json
{
  "n": 10,
  "slug": "internet",
  "villain": "Лагоед",
  "title": "Как работает интернет: путь одного пакета",
  "sub": "Одна строка: о чём выпуск и зачем это безопаснику",
  "color": "#19c3ff",
  "minutes": 9,
  "diff": 1,
  "district": "Фундамент",
  "motto": "Девиз злодея, одна фраза",
  "learn": ["4 пункта «Что ты узнаешь»", "...", "...", "..."],
  "fn": [["Термин", "Определение в одну фразу"]],
  "quiz": [{"q": "Сценарий-вопрос", "o": ["вариант", "вариант", "вариант"], "a": 1, "w": "Почему так"}],
  "iv": {"q": "Вопрос с собеседования", "a": "Сильный ответ одним абзацем"},
  "seo": "Короткая фраза для поиска: «DNS простыми словами: ...»",
  "emblem": "Один символ или короткое слово для постера злодея в шапке (например ✂ или pip)"
}
```
Квиз — 3 вопроса (они попадают в «Повторение»), fn — 4–6 терминов. Факты точные.

## Дополнительно для выпусков 23+
```json
{
  "district": "Веб-квартал",          // или "Завод", "Штаб защиты", "Лаборатория", "Облака", "Подполье"
  "seoTitle": "до 60 знаков: «Тема простыми словами: …»",
  "seoDesc": "до 160 знаков: что узнает читатель, с главными запросами",
  "seoTerm": "термин из fn, чьё определение станет первой строкой конспекта",
  "anchor": "текст ссылки на этот выпуск в «Читай также» (с главным запросом)",
  "related": [5, 4, 1, "MHttp"]       // 2–4 номера выпусков или ключи шпаргалок (MHttp, MPorts, MLinux, MGit, MOwasp)
}
```
Основной запрос из Wordstat ставь в seoTitle, H2 фрагмента и первую фразу истории (без переспама).
