Linux: команды на каждый день

Сначала думай, потом Enter. Застрял — man команда или команда --help.

Где я и что тут

pwd · ls -la

pwd — в какой папке стою, ls — что тут лежит.

  • -l — подробно: права, владелец, размер, дата.
  • -a — показать и скрытые файлы (их имена начинаются с точки).
cd /var/log · cd .. · cd ~
  • Путь с / в начале — от корня, без него — от текущей папки.
  • .. — на папку выше, ~ — домой.

Файлы и папки

mkdir -p proekt/src
  • -p — создать и все промежуточные папки, без ошибки, если уже есть.
cp -r src backup · mv old.txt new.txt
  • -r — копировать папку целиком, со всем внутри. mv переносит и переименовывает.
rm file.txt · rm -r папка
  • Корзины нет: удалено — значит, удалено.
  • -r — с содержимым. С -f (без вопросов) будь вдвойне осторожен.
cat · less · head -n 20 · tail -f
  • cat — вывести файл целиком, less — листать (выход: q).
  • head -n 20 — первые 20 строк. tail -f — следить за концом файла вживую, удобно для журналов.

Поиск

grep -rin "password" .
  • -r — во всех файлах папки, -i — без разницы, большие буквы или маленькие, -n — с номерами строк.
find . -name "*.log"
  • Найти файлы по имени, начиная с текущей папки (.).

Права

-rw-r-----: тип, потом по три буквы для владельца, группы и остальных. r = 4 читать, w = 2 менять, x = 1 запускать (для папки — входить).

chmod 640 db.conf
  • 6 = 4+2 владельцу (читать и менять), 4 группе (читать), 0 остальным.
  • Частые: папка и скрипт 755, секрет 600 или 640.
chown root:shop db.conf
  • Сменить владельца и группу: владелец:группа.
sudo команда · whoami · id
  • sudo — выполнить с правами root. whoami и id — кто я и в каких я группах.

«Permission denied» — не повод для 777

Права 777 — «всем всё». Сначала выясни, кому именно и какой доступ нужен. И службы не запускают от root.

Процессы

ps aux · top
  • a — процессы всех пользователей, u — с владельцем и нагрузкой, x — и те, что без терминала. top — то же вживую (выход: q).
kill 1234 · kill -9 1234
  • Попросить процесс с номером 1234 завершиться. -9 — убить без разговоров, если не слушается.

Диск, сеть и мелочи

df -h · du -sh папка · free -h
  • -h — размеры по-человечески (K, M, G). du -s — итог по папке, free — память.
ip a · ss -tulpn · curl -I https://example.com
  • ip a — мои адреса. ss: -t TCP, -u UDP, -l кто слушает, -p какая программа, -n номера вместо имён.
  • curl -I — показать только заголовки ответа сайта.
| · > · >> · history
  • | — передать вывод следующей команде: ps aux | grep nginx. > — записать в файл (перезапишет), >> — дописать в конец.
