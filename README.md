# Сайт CyberComics

## Как сайт попадает на cybercomics.ru
1. Каждый push в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`):
   сборка `node src/build.js && node src/prerender.js`, готовые файлы уходят в ветку `site`.
2. На хостинге reg.ru раз в 5 минут крон запускает `deploy/pull.sh`: если в `site` новая сборка,
   он скачивает её и обновляет папку `~/www/cybercomics.ru`.
   Команда крона: `curl -fsSL https://raw.githubusercontent.com/abv-1314/cybercomics/main/deploy/pull.sh | sh`
   (репозиторий должен быть публичным, иначе хостинг не скачает сборку).
Руками ничего распаковывать не нужно. Статус сборки — вкладка **Actions** в репозитории.

Готовый сайт лежит в папке `dist/`. Его можно залить на любой статический хостинг
(GitHub Pages, Cloudflare Pages, Netlify, Яндекс Object Storage, обычный хостинг с FTP).

## Что внутри
- `/` — главная с городом и выпусками
- `/vypuski/<тема>/` — выпуски 1–9 и вышедшие выпуски Фундамента 10–22, у каждого свой адрес, заголовок и описание для поиска
- `/povtorenie/` — «Прокачаться» (повторение по выпускам), `/arkada/` — «Разминка» (кроссворды и игры)
- `/baraholka/` — «Барахолка»: тут тратят биты (+50 за прочитанный выпуск, +10 за верный ответ). Методички и шпаргалки
  лежат на `/baraholka/git/`, `/baraholka/owasp/`, `/baraholka/http-kody/`, `/baraholka/porty/`, `/baraholka/linux/`.
  Их тексты — фрагменты `concepts/manuals/<имя>.html` (листы `.mn-page`, `data-preview` — бесплатный разворот),
  страница — компонент `Manual`, список — `MANUALS` в `src/build.js`. Старый адрес `/lavka/` переадресует на `/baraholka/`.
- шрифты и картинки лежат на самом сайте, запросов к Google нет
- прогресс читателя (прочитанные выпуски, ответы, биты) хранится в его браузере

## Как пересобрать
```
node src/build.js && node src/prerender.js
```
Когда будет домен и канал:
```
SITE_URL=https://твой-домен.ru VK_URL=https://vk.com/сообщество TELEGRAM_URL=https://t.me/канал node src/build.js && node src/prerender.js
```
Тогда появятся `sitemap.xml`, canonical-ссылки и кнопки на Telegram.

Подвал и данные (src/runtime/legal.js, тексты страниц в src/legal/):
- `CONTACT_EMAIL=почта` — строка «Связь: …» в подвале и на страницах данных.
- `METRIKA_ID=номер счётчика` — включает окно про cookie и Яндекс.Метрику (грузится только после «Принять»,
  Вебвизор выключен), полную политику `/privacy/` и согласие `/soglasie/`. Без него Метрики нет, `/privacy/` — короткая
  записка «мы ничего не собираем».
- `OPERATOR="…"` — кто оператор данных в политике. Не задан — «владелец сайта <домен>».
- В подвале каждой страницы: 12+, «Данные», «Родителям», «Перенести прогресс» (код для другого устройства, без регистрации).

Исходники макета — `src/pages/*.dc.html`. Правки макета вносятся там, сайт пересобирается командой выше.

## Поиск, скорость и выкладка
- Боевая сборка: `SITE_URL=https://cybercomics.ru CONTACT_EMAIL=cybercomics@yandex.ru node src/build.js && node src/prerender.js`.
- `YANDEX_VERIFICATION=код` и `GOOGLE_VERIFICATION=код` — мета-теги подтверждения прав (Яндекс.Вебмастер, Search Console),
  ставятся только на главную. `INDEXNOW_KEY=ключ` — файл ключа IndexNow; после выкладки `node src/seo.js ping`.
- Title/description, canonical, Open Graph, JSON-LD, sitemap.xml (lastmod — по дате изменения исходников), robots.txt,
  llms.txt — `src/seo.js`. Внимание: при сборке из свежего `git clone` даты файлов = дата клона, lastmod будет одинаковым.
- Портреты злодеев: `src/static/img/villain-N.webp` (720 px) и уменьшенные копии `-360.webp`, `-540.webp` для srcset.
  Новый портрет — положить все три файла (копии: `python3 -c "from PIL import Image; …"` или любой конвертер, качество 80).
- CSS и JS подключаются с `?v=<хеш>`: изменился файл — изменился адрес, поэтому их можно кешировать на год.
- Иконки: `src/static/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192/512.png`, `site.webmanifest`.
- nginx: `deploy/nginx.conf` (https, www → без www, gzip, кеш, 404, `/lavka/` → `/baraholka/`).
  Выкладка: `rsync -a --delete dist/ user@server:/var/www/cybercomics/`.

## Тела выпусков из фрагментов
Тело выпуска (история, битва, вопрос с собеседования, шпаргалка) берётся из файла
`concepts/issues/<slug>.html` (контракт: `concepts/issues/CONTRACT.md`). Копии в `src/` нет:
`src/build.js` читает эти файлы при каждой сборке. Чтобы обновить выпуск, поправь фрагмент
и пересобери сайт командой выше. Для просмотра без сервера:
```
PREVIEW=1 node src/build.js && PREVIEW=1 node src/prerender.js   # → preview/, открывается через file://
```
Как это работает:
- Нет фрагмента у выпуска — остаётся прежнее тело из `ISSUES` с квизом, вопросом и сносками.
- Есть фрагмент — `IMGROOT` заменяется на относительный путь `../../assets/img`, и фрагмент
  кладётся в `<template id="ix-fragment">` на странице выпуска. Тело выпуска становится
  игрушкой `ix` (`src/static/js/toys.js`). Она вставляет копию шаблона и запускает её
  `<script>` один раз. Квиз, вопрос с собеседования и сноски сайта при этом скрываются.
  Шапка, «Что ты узнаешь» и навигация остаются. Данные `ISSUES` не меняются («Прокачаться» и биты
  работают как раньше).
- «Прочитано»: выпуск отмечается, когда читатель долистал до конца фрагмента.
- `prerender.js` запекает разметку фрагмента без скриптов, чтобы текст видели поисковики.
- `IX_DIR=папка` берёт фрагменты из другой папки. Это удобно для проверки.
- Выпуски Фундамента 10–22 подключаются по паспорту `concepts/issues/<slug>.meta.json` (формат: `concepts/issues/META.md`)
  рядом с фрагментом. Есть паспорт и фрагмент — выпуск появляется в списке, фильтре, навигации, «Прокачаться», а кирпич
  Фундамента на главной становится ссылкой. Нет паспорта (или он битый) — выпуска на сайте просто нет. Портрета у этих
  выпусков нет: шапку и карточку рисует постер `VillainArt kind="poster"` (имя злодея, `emblem`, растр, цвет выпуска).
- Страница всегда открывается с шапки (если в адресе нет `#якоря`): прокрутка с прошлой страницы не восстанавливается.
