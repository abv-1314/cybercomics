Linux: команды на каждый день

Сначала думай, потом Enter. Застрял — man команда или команда --help.

Где я и что тут

pwd · ls -la

pwd — в какой папке стою, ls — что тут лежит.

  • -l — подробно: права, владелец, размер, дата.
  • -a — показать и скрытые файлы (их имена начинаются с точки).
cd /var/log · cd .. · cd ~
  • Путь с / в начале — от корня, без него — от текущей папки.
  • .. — на папку выше, ~ — домой.

Файлы и папки

mkdir -p proekt/src
  • -p — создать и все промежуточные папки, без ошибки, если уже есть.
cp -r src backup · mv old.txt new.txt
  • -r — копировать папку целиком, со всем внутри. mv переносит и переименовывает.
rm file.txt · rm -r папка
  • Корзины нет: удалено — значит, удалено.
  • -r — с содержимым. С -f (без вопросов) будь вдвойне осторожен.
cat · less · head -n 20 · tail -f
  • cat — вывести файл целиком, less — листать (выход: q).
  • head -n 20 — первые 20 строк. tail -f — следить за концом файла вживую, удобно для журналов.

Поиск

grep -rin "password" .
  • -r — во всех файлах папки, -i — без разницы, большие буквы или маленькие, -n — с номерами строк.
find . -name "*.log"
  • Найти файлы по имени, начиная с текущей папки (.).
