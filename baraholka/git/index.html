Git в одну строчку

Git — программа, которая ведёт журнал всех версий проекта: кто, что, когда и зачем поменял. К любой версии можно вернуться, а вдвоём (и вдесятером) можно работать над одним кодом и не затирать друг друга.

Словарик первой страницы

  • Репозиторий (repo) — папка проекта плюс скрытая папка .git, где живёт вся история. Удалишь .git — удалишь историю.
  • Рабочая папка — файлы, которые ты видишь и правишь прямо сейчас.
  • Индекс (staging area) — «корзина на кассе»: сюда ты складываешь изменения, которые пойдут в следующий коммит.
  • Коммит — сохранённый снимок проекта с подписью. Про него — следующая страница.

Зачем индекс, если можно сразу?

Чтобы собирать аккуратные коммиты. Поправил кнопку и опечатку в README? Сделай два коммита: git add только нужный файл — и коммить его отдельно.

1

1Коммит — это вагон

Каждый коммит — снимок всего проекта плюс подпись: автор, время, сообщение и ссылка на предыдущий коммит. Коммиты сцепляются в цепочку, как вагоны в поезд (помнишь выпуск №18 про Git?).

У каждого коммита есть хеш — отпечаток из 40 символов вроде 9e4b021c…. Обычно хватает первых 7. Хеш считается из содержимого и из хеша предыдущего коммита, поэтому тихо подменить старый коммит нельзя: поменяешь хоть букву — у него и у всех следующих будут новые номера.

Первый раз на компьютере

git config --global \
  user.name "Соня"
git config --global \
  user.email "sonya@example.com"

Это просто текст, который попадёт в коммиты. Проверки, что ты правда Соня, тут нет. Для этого есть подпись коммитов ключом.

Цикл, который ты будешь делать сто раз в день

# сделать из папки репозиторий (один раз)
git init
# что поменялось? что в индексе?
git status
# положить файл в индекс
git add game.js
# сохранить снимок с подписью
git commit -m "Мины: 12 вместо 10"
# история, по строчке на коммит
git log --oneline

плохо: fix, asdf, правки

Через месяц ты сам не поймёшь, что тут было.

хорошо: Счётчик мин не уходит в минус

Что изменилось и зачем. Коротко, как заголовок.

Правило отличника

Перед каждым коммитом — git status и git diff --staged. Две секунды, а ловят и случайный файл, и пароль, который чуть не уехал в историю.
